# 02-数据（数据源登记 · 不直接存放数据本体）

> **可选区**：默认不建，`create-instance.ps1` 加 `-IncludeOptionalZones` 或按需自行创建。
> 登记表模板：通用空表单见 `_workspace/_表单/_模板-数据源登记表.md`；本体在旧目录/外部盘，本目录只登记；AI 按绝对路径直达并按需点读。

| 数据 | 现状位置（绝对路径） | 性质 | 约束 | 状态 |
|---|---|---|---|---|
| <数据源> | `D:\<工作区根>\<实例名>\...\` | 只读原始数据 | <来源/更新方式/红线> | 待迁移 |
| <外部盘数据> | `E:\<路径>\` | 本地数据 | 只读分析；<体量> | 现役（不搬） |
| <已复制副本> | `D:\<工作区根>\<实例名>\03-知识输入\<主题>\` | 知识副本 | <体量>；本体只读保留 | 已复制 |

## 路径与可达性前提

- 本表一律**绝对路径**；AI 从任意启动目录直达（相对路径按各自目录解析会失败）。
- 外部盘依赖挂载；旧目录/外部数据源保留期或收尾（D6）后路径失效，届时更新本表。
- 大型数据源只读，按需点读/检索，禁止写入。
