# 工作区管理模板 · 落地检查清单（v0.4：阶段化 + 每项附验证方式）

## 阶段 1：骨架

- [ ] 复制 `_workspace/` 到工作区根
  - 验证：`00-总入口.md` 等编号规则 + `.gitignore` + `_handoff/` 存在
- [ ] 根 `README.md`：目录地图、硬约束、**当前主线（指向 `_handoff/README.md` 或进行中任务）**
- [ ] 根 `AGENTS.md` 指向 `_workspace/00-总入口.md`
  - 验证：读取文件确认第 1 条路径
- [ ] 核心目录 `01-文档` `04-工具` README + AGENTS；可选区（`02-数据` `03-知识输入`）按需建
  - 验证：逐目录 `Test-Path README.md / AGENTS.md`；AGENTS 第 1 条均指向 00-总入口
- [ ] `01-目录索引.md` 登记所有目录且为**绝对路径**
  - 验证：抽查路径均为 `盘符:\...` 形态
- [ ] `02-跨目录约束.md` 登记保护目录与凭据
- [ ] `.code-workspace` 挂载所有目录
  - 验证：folders 列表与 01-目录索引 一致

## 阶段 2：内容迁移

- [ ] 迁移/改名后**旧路径引用检查**（A3，提交前必查）
  - 验证：`rg -n "旧目录名|旧文件名" .` 无残留旧路径引用（或确认全部更新；覆盖 md 链接 / README / AGENTS / 登记表 / 脚本路径）
- [ ] 数据源登记表（`_表单/_模板-数据源登记表.md`）补全：绝对路径 + 可达性前提 + 体量；大型数据源建 `02-数据/索引/`（可选区，按需）
- [ ] 旧目录保持只读，未直接修改
  - 验证：旧仓 git status 无意外改动

## 阶段 3：验证

- [ ] 入口链：从任意目录启动 AI 能读到工作区概况与续接索引
  - 验证：各 AGENTS 均指向 00-总入口；新会话能读到 `_handoff/README.md`
- [ ] git init 逐仓核对（与续接文档记录一致）
  - 验证：每仓 `git rev-parse --is-inside-work-tree`
- [ ] 首次提交前检查：无凭据 / 大文件 / 嵌套 `.git` / zip
  - 验证：`git diff --cached --name-only | rg '\.(token|zip|pem|key)$'` 为空；嵌套 `.git` 扫描为空
- [ ] 三仓/各仓首提交（需用户确认）；`git push` 需用户确认 + 远端地址

## 阶段 4：收尾（D6 类）

- [ ] 旧目录移出 `.code-workspace`（用户确认后）
  - 验证：folders 移除且保存
- [ ] 同步更新失效路径：01-目录索引 / 02-跨目录约束 / 数据源登记表（可选区按需）/ 根 README
- [ ] 旧目录归档或删除前用户确认；过渡期文件（如 `00-AI规则/` 其余）随旧目录归档
- [ ] 更新续接文档状态与 `_handoff/README.md` 索引
