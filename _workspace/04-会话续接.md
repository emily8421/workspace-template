# 会话续接机制

## 唯一位置

- `_handoff/` 是本工作区续接文档唯一存放处。
- 按目录分子目录：`_handoff/<目录名>/`；跨目录任务放 `_handoff/共享/`；确认收尾后移入 `_handoff/归档/`。

## 命名

`YYYYMMDD-<任务短名>-续接.md`（日期前缀保证排序）。

## 模板

复制 `_handoff/_模板-续接文档.md`。必含小节：日期 / 状态（进行中|已完成|已归档）/ **当前主线或下一任务** / 一句话现状 / 关键位置表 / 核心数字与结论 / 硬约束 / 踩坑记录 / 待办（续接点）/ 新会话怎么接。

## 主线程指针（A4）

- `_handoff/README.md` 顶部维护「**当前主线/下一任务**」一行，指向进行中任务或写「无」。
- 每份续接文档的「当前主线或下一任务」字段与之呼应；新会话先读该指针再接任务。

## 索引与生命周期

1. 新文档生成后必须在 `_handoff/README.md` 登记一行：日期 | 任务 | 目录 | 状态 | 路径。
2. 状态流转：进行中 → 已完成（任务收尾时更新）→ 已归档（确认后移入 `归档/`，保留历史不删除）。
3. 每次大任务收尾或每周整理一次索引。

## 强制规则

- 任务中途或收尾时若未完成，必须生成/更新续接文档并登记索引。
- 任务已完成则更新状态行，不新增文档（除非有新子任务）。
- 新会话进入工作区，先读 `_handoff/README.md`。
