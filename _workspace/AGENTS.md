# AI Agent 入口（_workspace · 治理）

从本目录或本目录任意子目录启动 AI 后，先读取并遵守：

1. `00-总入口.md`（全局规则唯一入口，按其中读取顺序继续）
2. `01-目录索引.md`（工作区地图）
3. 当前所在子目录的 `AGENTS.md` / `README.md` 与自有规则（如有）

新开会话先查 `_handoff/README.md`（续接索引）。
续接文档写入 `_handoff/<目录名>/`。

## 为什么本文件存在（AI 引导机制）

- 本目录是独立 git 仓库。Codex 等 AI CLI 以「git 仓库根」为规则发现边界：从本仓任意位置启动只会自动加载本文件，不会自动加载实例根（上层）的 `AGENTS.md`。治理仓库自身必须有入口文件，才能保证「从治理目录进入也有引导」。
- `.code-workspace` 挂载不等于 AI 引导：把目录加进工作区不会让 AI 自动读到本仓规则；引导靠各目录自己的 `AGENTS.md` 链回本文件（新目录引导三件事见 `01-目录索引.md` 登记约定）。
