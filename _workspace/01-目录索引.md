# 目录索引（工作区地图）

本表是「从任意目录进入都能获得工作区概况」的依据。新增/改名目录时在此登记，并同步根 README 目录地图。

> 路径约定（v0.4）：本表一律使用**绝对路径**（如 `D:\<工作区根>\<实例名>\01-文档\`、`E:\plugin-project-data`）。
> AI 从任意启动目录（cwd）按绝对路径直达；相对路径按各自目录解析会失败，禁止使用。

| 目录（绝对路径） | 类型 | 用途 | 入口文件 | 只读 | git 仓库 | 负责人 | 备注 |
|---|---|---|---|---|---|---|---|
| `D:\<工作区根>\<实例名>\_workspace\` | 治理 | 全局规则/索引/续接 | `AGENTS.md`（→ `00-总入口.md`） | 否 | 独立仓/工作区仓 | — | 本表 |
| `D:\<工作区根>\<实例名>\01-文档\` | 文档 | <用途> | README.md / AGENTS.md | 否 | 独立仓/工作区仓 | | |
| `D:\<工作区根>\<实例名>\02-数据\` | 数据 | <用途> | README.md / AGENTS.md | 是 | 无 | | 只登记不存本体；索引见 `02-数据\索引\` |
| `D:\<工作区根>\<实例名>\03-知识输入\` | 知识 | <用途> | README.md / AGENTS.md | 是 | 无 | | 只读参考；索引见 02-数据 |
| `D:\<工作区根>\<实例名>\04-工具\` | 工具 | <用途> | README.md / AGENTS.md | 否 | 独立仓/工作区仓 | | 脚本与使用说明 |
| `D:\<工作区根>\<外部目录>\` | 代码 | <用途> | README.md / AGENTS.md | 否 | 现有仓保持 | | 外部目录用 ../ 或绝对路径引用 |
| `E:\<外部数据盘>\<目录>\` | 数据 | <用途> | README.md | **是** | 各仓自带 | | 可达性：依赖盘符挂载 |

## 类型约定

- 文档：人读产物（需求/方案/过程记录/知识）
- 数据：原始输入（只读，标注来源、更新方式与约束）
- 知识：参考依据（只读，来源登记于 02-数据）
- 代码：可运行工程（SDK/工具源码）
- 工具：脚本与使用文档
- 治理：`_workspace/`（规则/索引/续接）
- 归档：被取代/旧版材料

## 登记约定（新增目录必须）

1. 建 `README.md`（用途/入口/约束）
2. 建 `AGENTS.md`（AI 入口：先全局规则再子目录规则）——**所有目录统一 README + AGENTS，含数据登记区**
3. 本表登记一行（绝对路径）
4. 根 README 目录地图同步

> AI 引导三件事（展开）：①目录内建 `AGENTS.md`（链回 `_workspace\00-总入口.md`，路径用绝对路径）；②若为独立 git 仓库，`AGENTS.md` 放仓根（AI 只从 git 根向下发现规则）；非 git 目录仅在直接以该目录为启动目录时生效，子目录不自动向上找；③登记本表与 `07-VSCode工作区挂载登记.md`（如需挂载）+ 运行 `04-工具\sync-vscode-workspace.ps1` 同步。
> 注意：`.code-workspace` 挂载本身不产生 AI 引导；引导只靠各目录 `AGENTS.md` 链回治理入口。

## 可达性前提（登记外部/旧目录时填写）

- 外部盘（E:/ 等）：依赖盘符挂载；换机器/拔盘后不可达。
- 迁移期旧目录：保留期间可达；收尾（D6）后路径失效，届时更新本表与 02-数据 登记表。
