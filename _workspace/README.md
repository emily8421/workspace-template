# _workspace（工作区治理区）

承载工作区的全局规则、目录索引、git 机制、通用文档管理原则与会话续接。

- 规则入口：`00-总入口.md`（唯一）
- 目录地图：`01-目录索引.md`
- 跨目录约束：`02-跨目录约束.md`
- git 机制：`03-git管理.md`
- 会话续接：`04-会话续接.md`（文档在 `_handoff/`，索引见 `_handoff/README.md`）
- 通用文档管理原则：`08-通用文档管理原则.md`（A1-A7：事实源/归档/断链/主线程/路径/可追溯/语言表达）
- 工具管理：`09-工具管理.md`（工具注册表/生命周期/临时脚本边界）
- 空表单库：`_表单/`（数据源登记表 / 需求文档雏形）
- 实例参考示例：`_参考示例/`（业务形态示例，非规则）
- 本目录建议独立 git 仓（拓扑 A）或随工作区单仓（拓扑 B），见 `03-git管理.md`

> 本目录整体可复制到新工作区；落地步骤见 `落地检查清单.md`（模板包根目录）。
