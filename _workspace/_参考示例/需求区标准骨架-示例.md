# 需求区标准骨架（示例）

> **性质**：实例业务产物示例（来源 miiot_plugin_develop_system 的 `03-自动化系统/1-需求/`）。**需求驱动型项目可用，通用模板不内置**；空表单见 `../_表单/_模板-需求文档雏形.md`。

## 结构

```
1-需求/
├── 01-当前阶段分析/     （当前推进的分析/数据产出，最新事实源）
├── 02-历史归档/         （已归档旧结构，A2 范围变更→整体归档）
├── 10-用户需求说明书.md  （URS，见 C3 示例）
└── 11-数据提供与清洗要求.md
```

## 要点

- 目录编号分层：`01-当前阶段分析`（现役）↔ `02-历史归档`（已取代），呼应 A1/A2。
- 事实源锚点固定命名，范围变更整体归档重建新树，不原地打标签。
- 需求区结构由实例自定，非模板规则。
