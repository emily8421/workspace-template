# URS 与数据清洗要求（示例）

> **性质**：实例业务产物示例（来源 miiot_plugin_develop_system：`10-用户需求说明书.md`、`11-数据提供与清洗要求.md`）。**带业务字段的具体形态**，与空表单 `../_表单/_模板-需求文档雏形.md` 对照使用。

## URS 具体形态（节选示意）

```markdown
# <需求名> · 用户需求说明书
## 1. 背景与目标            # 为什么做、成功标准
## 2. 范围                  # IN / OUT（明确排除）
## 3. 功能需求              # 编号 | 需求 | 优先级 | 验收
## 4. 数据清单              # 输入来源/格式/更新；交付物形态/位置
## 5. 待确认问题            # Q-001~010，标注影响范围与来源
## 6. 关联                  # 基线编号 F-xxx / 需求 D-xxx / 续接文档
```

## 数据清洗要求具体形态（节选示意）

```markdown
- 来源 xlsx：开发类型含「0EM+小修改」笔误 → 统一为 OEM+小改
- 编码：xlsx 用 openpyxl 读，注意编码
- 处理过程留记录（A6）：做了什么 / DONE / 排除项
- 输出：机读 CSV + 可评审 md 结论分离，不把结论塞进数据
```

> 字段随业务变化，本示例仅为形态参考；模板只提供去业务字段的空骨架（B3）。
