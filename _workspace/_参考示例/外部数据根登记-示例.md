# 外部数据根登记（示例）

> **性质**：实例业务产物示例（来源 miiot_plugin_develop_system 的数据盘登记模式）。**拓扑相关，非通用规则**——多数实例没有实例目录树之外的外部数据根，不需要本示例。仅当出现「实例目录之外的数据盘/数据根」时参考本形态登记。
> 通用登记表见 `../_表单/_模板-数据源登记表.md`。

## 适用场景

数据本体放实例目录之外（如独立数据盘、远端数据根），实例目录只放登记与链接。

## 登记形态（占位符化）

| 层 | 内容 | 说明 |
|---|---|---|
| 数据根 README | `<盘符>:\<数据根名>\README.md` | 目录地图 + 更新方式 + 边界声明 |
| 索引清单 | `<数据根名>\索引\` | 各数据区清单/地图（机读 + 人读） |
| AI 入口 | `<数据根名>\AGENTS.md` / `CLAUDE.md` | 链回实例 `_workspace/00-总入口.md`（绝对路径） |
| 挂载登记 | `_workspace/07-VSCode工作区挂载登记.md` | 绝对路径一行（`mount: true/false`） |
| 保护登记 | `_workspace/02-跨目录约束.md` | 保护目录清单一行（只读） |
| 数据源登记 | `_workspace/_表单/_模板-数据源登记表.md` | 位置/性质/约束/状态/负责人 |

## 边界声明（数据根 README 必备）

- 数据根**不得作为可执行脚本的长期入口**（一次性脚本放系统临时区，见 `_workspace/09-工具管理.md`）。
- 数据根只读；更新走登记好的流程，不直接改本体。
- 可达性依赖盘符/挂载：换机器或未挂载时不可达，路径以登记表为准。

## 何时模板化

- 单个外部数据根：按本示例登记即可。
- 出现**第二个**外部数据根：把本形态提炼成模板规则再上（避免单例直接进规则造成污染）。
