# 03-知识输入（参考依据 · 只读）

> **可选区**：默认不建，`create-instance.ps1` 加 `-IncludeOptionalZones` 或按需自行创建。

存放「只做参考、不可修改」的知识输入：外部文档、共享基础、知识库整理版等。
本目录**只读**：禁止修改/新增（除索引维护外）；业务产出一律写 `01-文档/`。

## 存放规则（二分）

- **小型参考文档**（md/文本/小图）：复制只读副本到 `03-知识输入/<主题>/`。
- **大型知识数据**（>10MB / 海量文件）：默认本体不入库，只放索引 README，数据源登记在 `02-数据/README.md`。
  - 例外：高频使用 / 用户明确要求落地副本时，可复制完整副本到 `03-知识输入/<主题>/`（不入 git），但**必须**在 `02-数据/README.md` 登记「已复制副本」事实与体量。
  - 复制与否是决策点：默认索引，除非用户要求；复制后本体仍只读保留。

## 约束

- 只读目录：禁止修改/删除/移动/重命名/覆盖（登记于 `_workspace/02-跨目录约束.md`）。
- 不入 git 仓（与 `01-文档` 仓无关）。
- 凭据禁入；发现凭据类文件立即报告并隔离。
