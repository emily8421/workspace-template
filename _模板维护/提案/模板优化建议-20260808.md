# workspace-template 优化建议（2026-08-08 实例会话复盘 · 通用性修订版）

> **状态：已落地（v1.0，2026-08-08）**——本提案全部待办已按 v1.0 落地，本文件保留为决策记录。
> **性质**：对 workspace-template 的**优化提案**（供模板维护者评估采纳），**非现役实例规则**。
> **来源**：`miiot_plugin_develop_system` 实例 2026-08-08 会话复盘（需求区重构、数据双盘安置、URS 编写）。
> **核心原则**：**模板 = 通用文档管理骨架；业务目录 = 实例自由区**（处理日常事务，可能是项目、也可能是其他事务性工作，业务结构差异大属正常，模板不约束）。

---

## 一、模板定位（本版修订前提）

- 模板管"**怎么管理文档**"（通用原则），不管"**管理什么**"（业务结构）。
- 业务目录（如 学习记录 / V3.5项目 / 自动化系统 / 需求区）差异大，由实例自定。
- **回流模板时提炼"通用原则"，不回流"业务结构"**。

## 二、01-04 顶层目录通用性评估

| 目录 | 通用性 | 建议 |
|---|---|---|
| `01-文档` | 高（任何事务都有书面产出） | **保留**；内部业务子目录**不由模板规定** |
| `02-数据` | 中（数据处理型任务需要；纯文档/事务任务可不需要） | 模板给"数据源登记表"空表单；**目录按需建，不强制** |
| `03-知识输入` | 低（参考知识库仅特定任务需要） | **可选区**，默认不建 |
| `04-工具` | 中高（有脚本就需要） | **保留**；给"路径从配置读"约定 |

**结论**：模板提供「最小通用骨架 + 可选区」，**不固定 4 个目录**。只有 `01-文档`、`04-工具` 接近通用；`02-数据` 可选、`03-知识输入` 按需。

## 三、建议按通用性分层（原 8 条重分类）

### A. 通用原则（✅ 进模板）

| # | 原则 | 原建议 |
|---|---|---|
| A1 | **唯一事实源锚点**：约定固定命名/位置（如 `00-事实源-<日期>.md`）；范围变更时旧文档一律降级/归档 | ③ |
| A2 | **范围变更→整体归档、重建新树**，不原地打标签/加子目录 | ②（归档规则部分） |
| A3 | **引用完整性检查**：移动/重命名后必跑断链 grep，写入提交前 checklist | ④ |
| A4 | **handoff 主线程指针**：`_handoff/README.md` 顶部"当前主线/下一任务"一行 | ⑥ |
| A5 | **脚本路径从配置/登记读**，不硬编码绝对路径；提供路径变更同步清单 | ⑦ |
| A6 | **处理过程可追溯**：任何清洗/转换/加工留记录（做了什么/DONE/排除项） | ⑧ |

### B. 模板化空表单（✅ 进模板，业务字段由实例填）

| # | 空表单 | 说明 |
|---|---|---|
| B1 | **数据源/外部资产登记表** | 字段：位置/性质/约束/状态/负责人。**不分盘、不定形态等级**（如 L0-L4）——那些是实例数据布局，非通用 |
| B2 | **续接文档模板** | 现有 `_模板-续接文档.md`，建议补"当前主线/下一任务"字段（呼应 A4） |
| B3 | **需求文档雏形（URS 骨架）** | 通用化：范围 IN/OUT、功能需求、数据清单、待确认问题。**去业务字段**（model/spec/品类等由实例填） |

> 原 ①（数据地图）→ 拆为 B1（登记表，通用）+ C1（分盘地图，实例）；原 ⑤（输入材料归属）→ 并入 B1（外部输入即"外部资产"，登记归属）。

### C. 业务示例（❌ 不进模板，作实例参考存样）

| # | 示例 | 说明 |
|---|---|---|
| C1 | 分盘数据地图（D盘/E盘、L0-L4 形态） | 本项目数据布局，非通用 |
| C2 | 需求区标准骨架（事实源/当前分析/历史归档） | 需求驱动型项目可用，通用模板不内置 |
| C3 | URS / 数据清洗要求的具体形态 | 实例产出，可作样例但不进模板规则 |

## 四、通用模板的核心（只含三样）

1. **治理规则**：入口 / 目录索引 / 跨目录约束 / 凭据 / git / 会话续接（`_workspace` 的 00-04 类；**业务规则如"小米IOT平台数据约束"属实例级，不进通用模板**）
2. **通用文档管理原则**（见三 A：事实源锚点、范围变更归档、断链检查、handoff 主线程、路径从配置读、处理可追溯）
3. **可复用空表单**（见三 B：数据源登记表、续接模板、需求文档雏形）

## 五、待办（给模板维护者）

2. 按三 B 提供 3 个空表单（去业务字段）
3. 三 C 业务示例存为"实例参考"区，不并入规则
4. 顶层目录改为「最小通用骨架（01-文档 + 04-工具）+ 可选区（02-数据 / 03-知识输入）」
