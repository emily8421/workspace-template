# _模板维护（模板仓自身脚本与记录）

> 模板仓的机械区：维护脚本与历史提案归档。**整目录不复制进实例**（`create-instance.ps1` 排除清单已含本目录名）。
> 与 `04-工具/` 的区别：`04-工具/` 是实例骨架（复制给每个实例装自己的工具）；本目录只服务模板仓本身。

## 内容

| 文件/目录 | 用途 |
|---|---|
| `create-instance.ps1` | 从模板仓创建新工作区实例（默认核心骨架，`-IncludeOptionalZones` 加可选区） |
| `sync-template.ps1` | 模板 → 实例同步（dry-run / `-Apply`，front-matter 驱动） |
| `提案/` | 历次「模板优化建议-YYYYMMDD.md」归档（决策记录，落地状态见各文件头部标注与 CHANGELOG） |

## 约定

- 新脚本先加本目录，再在本 README 登记。
- 提案文件命名 `模板优化建议-YYYYMMDD.md`，定稿后标状态（待裁定 / 已落地 / 不采纳）并留档，不删除。
- 版本管理走根 `CHANGELOG.md`。
